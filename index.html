QAlgebra.jl

QAlgebra.jl provides symbolic tools for constructing and manipulating quantum operator expressions on structured composite systems of qubits, spins, and bosonic modes.

The core abstraction is the QSpace, which defines:

  • The symbolic variables (e.g. coupling constants),
  • The operator bases (e.g. Pauli, ladder, raising/lowering),
  • And the indexed structure of composite systems.

The examples below walk through defining a tensor-product space, the associated parameters and abstract operators and some basic manipulations of quantum expressions built from them.

Example: Constructing a State Space

The state space is defined by describing each subsystem—either as a single mode or an ensemble of replicated modes—declaring the symbolic operators, and listing the classical parameter groups. Operator sets can be custom objects or picked from the built-in Pauli, ladder, and PM collections. Ensembles can also be marked as continuum approximations when their parameter ranges are sampled densely.

using QAlgebra
subspace_def = SubSpaceDefinitions( h=QubitPM("beta"),
                                    i=Ensemble(3, 3, QubitPauli("sigma"), as_continuum=true),
                                    b=Ladder(max_magnitude=4))
op_def = OperatorDefinitions("A(i,t)", "B(U,H,i)")
var_def = ParameterDefinitions( "alpha",
                                "beta(t)" => t->t^2,
                                "delta_i" => QUniform(0,1,10),
                                "gamma_{i,j}(t,delta_i,delta_j)" => (t,gi,gj)->t*(gi-gj))
qspace = QSpace(subspace_def, op_def, var_def, max_t_ind=2)

Ensemble Configuration

When defining ensemble subsystems use Ensemble to collect the relevant metadata. The positional arguments specify how many operator indexes and summation indexes are reserved alongside the OperatorSet. Additional keyword arguments can be supplied, for instance to record the number of physically realised modes or to pre-register sample points that span the ensemble parameter space:

Ensemble(2, 1, QubitPauli("sigma"); num_modes=4)

During QSpace construction each ensemble automatically records which parameter groups (e.g. :gamma) act on it via the parameter_groups field, while samples and distribution remain available for later use when sampling ensemble parameter spaces.

Building, Printing and Modifying Expressions

You can build symbolic expressions using variables and operators:

expr = alpha * xi + Dag(b) * yi
expr

\[ {\hat{\sigma}}^{y}_{i}\hat{b}^\dagger+\alpha {\hat{\sigma}}^{x}_{i}\]

You can get the string and latex_string expressions via 

string(expr)
"σʸᵢb†+ασˣᵢ"
latex_string(expr)
" {\\hat{\\sigma}}^{y}_{i}\\hat{b}^\\dagger+\\alpha {\\hat{\\sigma}}^{x}_{i}"

We provide a number of useful operations, such as sums and products:

expr = ∑(:l, delta[:l] * yl) * ∑(:l, delta[:l] * yl * A())
expr

\[\sum_{l,m}^{=}\delta_{l}\delta_{m} {\hat{\sigma}}^{y}_{l}{\hat{\sigma}}^{y}_{m}\hat{A}(t)\]

The automatic decollision step rewrites the second summation so each factor acts on a unique index. You can still enforce explicit distinctness using neq:

neq(expr)

\[\sum_{l}^{\neq}\delta_{l}^{2} \hat{A}(t)+\sum_{l,m}^{\neq}\delta_{l}\delta_{m} {\hat{\sigma}}^{y}_{l}{\hat{\sigma}}^{y}_{m}\hat{A}(t)\]

Integrals follow the same interface:

qint = ∫("l", alpha * xl)
qint

\[\int_{\rho_{l}}\alpha {\hat{\sigma}}^{x}_{l}\,\mathrm{d}l\]

You can define differential equations of operator expectation values

qs = ∑(:l, alpha * xl)
diff_eq = d_dt(zi, alpha * qs + qs)
diff_eq

\[\frac{\text{d} \braket{{\hat{\sigma}}^{z}_{i}}}{\text{d}t} = \left(\alpha+\alpha^{2}\right) \braket{{\hat{\sigma}}^{x}_{i}}+\sum_{l}^{\neq}\left(\alpha+\alpha^{2}\right) \braket{{\hat{\sigma}}^{x}_{l}}\]

d_dt automatically normalises time indexes: if the equation only references a single time slot t_k, it is internally substituted to t_0 so subsequent manipulations operate on a canonical representation.

Operator Functions

We provide the following operator functions:

exp(expr)

\[ \exp\left(\sum_{l,m}^{=}\delta_{l}\delta_{m} {\hat{\sigma}}^{y}_{l}{\hat{\sigma}}^{y}_{m}\hat{A}(t)\right)\]

log(expr + zi)

\[ \log\left( {\hat{\sigma}}^{z}_{i}+\sum_{l,m}^{=}\delta_{l}\delta_{m} {\hat{\sigma}}^{y}_{l}{\hat{\sigma}}^{y}_{m}\hat{A}(t)\right)\]

power(expr, 2)

\[ \left(\sum_{l,m}^{=}\delta_{l}\delta_{m} {\hat{\sigma}}^{y}_{l}{\hat{\sigma}}^{y}_{m}\hat{A}(t)\right)^{2}\]

root(expr + zi, 2)

\[ \sqrt{ {\hat{\sigma}}^{z}_{i}+\sum_{l,m}^{=}\delta_{l}\delta_{m} {\hat{\sigma}}^{y}_{l}{\hat{\sigma}}^{y}_{m}\hat{A}(t)}\]
